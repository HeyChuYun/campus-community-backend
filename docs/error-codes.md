# 错误码约定

## 1. 设计目标

为避免多个服务复用同一组小整数错误码导致前端误判，本项目统一采用“按服务划分错误码区间”的方式管理业务状态码。

约定如下：

- `0`：成功
- `1000-1999`：`passport-service`
- `2000-2999`：`school-service`
- `3000-3999`：`content-service`
- `4000-4999`：`relation-service`
- `5000-5999`：`im-service`
- `9000-9999`：`gateway` 通用错误

## 2. passport-service

- `1001` `PASSPORT_CODE_INVALID_ARGUMENT`
- `1002` `PASSPORT_CODE_ACCOUNT_ALREADY_EXISTS`
- `1003` `PASSPORT_CODE_NICKNAME_ALREADY_EXISTS`
- `1004` `PASSPORT_CODE_INVALID_CREDENTIAL`
- `1005` `PASSPORT_CODE_ACCESS_TOKEN_INVALID`
- `1006` `PASSPORT_CODE_REFRESH_TOKEN_INVALID`
- `1007` `PASSPORT_CODE_ACCOUNT_UNAVAILABLE`
- `1008` `PASSPORT_CODE_REAUTH_REQUIRED`
- `1009` `PASSPORT_CODE_PERMISSION_DENIED`
- `1010` `PASSPORT_CODE_INTERNAL_ERROR`
- `1011` `PASSPORT_CODE_BEHAVIOR_VERIFY_FAILED`

## 3. school-service

- `2001` `SCHOOL_CODE_INVALID_CAPTCHA`
- `2002` `SCHOOL_CODE_INVALID_CREDENTIAL`
- `2003` `SCHOOL_CODE_SESSION_EXPIRED`
- `2004` `SCHOOL_CODE_REAUTH_REQUIRED`
- `2005` `SCHOOL_CODE_NOT_BOUND`
- `2006` `SCHOOL_CODE_AUTH_TICKET_INVALID`
- `2007` `SCHOOL_CODE_ALREADY_BOUND`
- `2008` `SCHOOL_CODE_REMOTE_ERROR`
- `2009` `SCHOOL_CODE_INTERNAL_ERROR`

## 4. content-service

- `3001` `CONTENT_CODE_INVALID_ARGUMENT`
- `3002` `CONTENT_CODE_NOT_FOUND`
- `3003` `CONTENT_CODE_PERMISSION_DENIED`
- `3004` `CONTENT_CODE_CONFLICT`
- `3005` `CONTENT_CODE_INTERNAL_ERROR`

## 5. relation-service

- `4001` `RELATION_CODE_INVALID_ARGUMENT`
- `4002` `RELATION_CODE_NOT_FOUND`
- `4003` `RELATION_CODE_ALREADY_EXISTS`
- `4004` `RELATION_CODE_PERMISSION_DENIED`
- `4005` `RELATION_CODE_INTERNAL_ERROR`

## 6. im-service

- `5001` `IM_CODE_INVALID_ARGUMENT`
- `5002` `IM_CODE_NOT_FOUND`
- `5003` `IM_CODE_PERMISSION_DENIED`
- `5004` `IM_CODE_CONFLICT`
- `5005` `IM_CODE_BLOCKED`
- `5006` `IM_CODE_DM_LIMIT_REACHED`
- `5007` `IM_CODE_READONLY_USER`
- `5008` `IM_CODE_UPSTREAM_ERROR`
- `5009` `IM_CODE_INTERNAL_ERROR`

## 7. gateway

- `9001`：网关调用下游 RPC 失败
- `9002`：网关参数或 JSON 结构不合法
- `9003`：网关发现下游响应缺少关键字段
- `9004`：网关聚合时确认资源不存在

## 8. 前端处理规则

- 只有 `1005` 和 `1006` 应被视为平台登录态失效。
- `1008` 表示需要重新校园授权，不应直接清空平台登录态。
- `2004` 表示校园授权失效，应引导用户重新完成校园授权。
- `5005/5006/5008` 等 IM 错误只属于私信业务，不允许再触发“跳回登录页”。
